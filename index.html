Paste into Outlook
  1. Outlook desktop (classic): File → Options → Mail → Signatures → New → paste with Ctrl+V → Save.
  2. New Outlook / Outlook on the web: Settings (gear) → Accounts → Signatures → New signature → paste → Save.
  3. Set it as default for new messages and replies/forwards if you want.
If Copy doesn't work in your browser, drag-select from the name to the bottom of the banner and press Ctrl+C.
