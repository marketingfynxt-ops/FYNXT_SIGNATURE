FYNXT Email Signature - Vercel site
===================================
index.html          -> the signature page (edit name/title/phone/email, click Copy)
assets/banner.gif   -> the animated banner. To change it, replace this file with
                       your own GIF using the SAME name (banner.gif), ideally
                       1360 x 180 px and under 1 MB, then redeploy.
assets/*.png        -> contact and social icons
vercel.json         -> caching settings (no need to edit)
